# Set (and reset) global httr configuration.

Set (and reset) global httr configuration.

## Usage

``` r
set_config(config, override = FALSE)

reset_config()
```

## Arguments

- config:

  Settings as generated by
  [`add_headers()`](https://httr.r-lib.org/dev/reference/add_headers.md),
  [`set_cookies()`](https://httr.r-lib.org/dev/reference/set_cookies.md)
  or
  [`authenticate()`](https://httr.r-lib.org/dev/reference/authenticate.md).

- override:

  if `TRUE`, ignore existing settings, if `FALSE`, combine new config
  with old.

## Value

invisibility, the old global config.

## See also

Other ways to set configuration:
[`config()`](https://httr.r-lib.org/dev/reference/config.md),
[`with_config()`](https://httr.r-lib.org/dev/reference/with_config.md)
