# Control where the response body is written.

The default behaviour is to use `write_memory()`, which caches the
response locally in memory. This is useful when talking to APIs as it
avoids a round-trip to disk. If you want to save a file that's bigger
than memory, use `write_disk()` to save it to a known path.

## Usage

``` r
write_disk(path, overwrite = FALSE)

write_memory()
```

## Arguments

- path:

  Path to content to.

- overwrite:

  Will only overwrite existing `path` if TRUE.
